# Ручная проверка в Telegram — Этап 0

Каркас платформы (спеки `docs/tasks/001-platform-core.md` и `docs/tasks/002-platform-bot.md`).
Модулей пока нет, поэтому проверяется только оболочка платформы и бот.

## Подготовка

- [ ] Поднят HTTPS-туннель к порту 5080 (например, cloudflared), его адрес будет `PublicUrl`.
- [ ] Заданы секреты (user-secrets или переменные окружения): `Bot:Token`, `Bot:WebhookSecret`, `Bot:PublicUrl`.
- [ ] Собран фронтенд: `cd webapp && npm run build`.
- [ ] Запущен сервер: `dotnet run --project src/Bot.Host`. В логе нет ошибок регистрации webhook и команд.
- [ ] В BotFather у бота настроена кнопка меню Mini App на `PublicUrl`.

## Бот

- [ ] `/start` в личке → приходит приветствие с кнопкой открытия Mini App.
- [ ] `/help` → приходят только команды платформы (`/start`, `/help`), модулей нет.
- [ ] `/foo` → приходит ответ про неизвестную команду.
- [ ] Обычный текст → приходит отдельный ответ для сообщения без команды.
- [ ] Бот добавлен в группу, там написан `/start` → бот молчит.
- [ ] `curl -X POST <PublicUrl>/bot/webhook` без заголовка `X-Telegram-Bot-Api-Secret-Token` → 401.

## Mini App

- [ ] При открытии кнопкой на секунду появляется «Загрузка…», затем «Привет, {ваше имя}!» и «Здесь пока ничего нет — разделы появятся скоро.».
- [ ] При переключении тёмной и светлой темы Telegram цвета приложения меняются без перезагрузки.
- [ ] `t.me/<бот>?startapp=ghost_x` → открывается главная с уведомлением «Ссылка не распознана — открыта главная.». Кнопки «Назад» нет.
- [ ] После любого перехода уведомление исчезает и больше не появляется, в том числе после «Назад».

## Вне Telegram

- [ ] `PublicUrl` в обычном браузере → заглушка «Откройте приложение в Telegram».
- [ ] `curl <PublicUrl>/api/platform/me` без авторизации → 401 с `code: auth_missing`.
- [ ] `curl <PublicUrl>/health` → 200 `{"status":"ok"}`.
