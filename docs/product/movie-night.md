# Бриф: модуль MovieNight («Киновечер»)

## Идея
Группа людей (обычно пара, но может быть любая компания) заранее собирает фильмы и сериалы,
которые хочет посмотреть. У каждого участника — **своя коллекция**. Вечером кто-то открывает Mini App,
жмёт «Выбрать» — сервер случайно выбирает кандидата из коллекций участников группы, с анимацией
«карточка вытягивается из мешка». Можно нажать «Ещё» или «Смотрим!». После просмотра фильм отмечается
как просмотренный в этой группе.

Основной сценарий использования: выбирают **вместе, на одном телефоне**; остальные участники
получают уведомление в боте о выбранном фильме.

## Модель данных

### Тайтл (каталог, общий для всех)
Один фильм или сериал = одна запись в каталоге, независимо от того, сколько людей его добавили.
- Категория: **Фильм** или **Сериал** (см. правило категорий ниже)
- Название (рус.), оригинальное название, год, жанры, длительность (для сериала — длительность серии,
  число сезонов), постер, краткое описание
- Внешние ID: TMDB ID, IMDb ID, Кинопоиск ID — любой из них однозначно идентифицирует тайтл
- Данные получены из внешнего источника и **сохраняются у нас** (кэш), а не запрашиваются при каждом показе

**Правило категорий.** Категория определяется форматом, а не жанром:
- Фильм — полнометражная лента: игровое кино, мультфильмы, аниме-фильмы. Мультфильм/аниме — это жанр.
- Сериал — многосерийное произведение, в том числе аниме-сериалы.
- Берётся из типа тайтла в источнике (в TMDB это `movie` / `tv`).

### Запись в коллекции (у пользователя)
«Этот тайтл есть в моей коллекции».
- Пользователь, тайтл, дата добавления
- **Теги** — как автор характеризует тайтл: предустановленные («Любимое», «Просто посмотреть»)
  и свои. Теги **видны другим участникам** групп. На случайный выбор теги **не влияют**.
  (Задел на будущее: подборки по тегам.)
- **Личная отметка «Я уже видел»** — пользователь смотрел тайтл раньше, сам или с другими.
  Показывается на карточке («Петя уже видел»), на случайный выбор не влияет.

Коллекция принадлежит пользователю, а не группе: если человек состоит в нескольких группах,
во всех используется одна и та же его коллекция.

### Группа
- Название, участники, порядок участников (по времени вступления) — нужен для режима «По очереди»
- Вступление по ссылке-приглашению `startapp=movienight_join_<код>`
- Любое количество участников; пользователь может состоять в нескольких группах
- Текущий ход в режиме «По очереди»

### Просмотр (событие группы)
«Группа посмотрела тайтл»: группа, тайтл, дата.
- Это и есть «просмотрено» для фильтра выбора. Просмотр в одной группе не влияет на другие группы.
- Если тайтл есть в коллекциях нескольких участников, он считается просмотренным для всей группы
  автоматически, потому что тайтл один.

### Сеанс выбора
Создаётся, когда нажали «Выбрать».
- Группа, кто запустил, режим, фильтры, список уже показанных кандидатов
- «Ещё» → следующий кандидат; уже показанные в этом сеансе не повторяются. Без ограничения числа нажатий.
- «Смотрим!» → тайтл получает статус **«Выбран на вечер»**, сеанс закрывается, участникам группы уходит
  уведомление в бот
- Позже по выбранному тайтлу: **«Посмотрели»** → создаётся Просмотр; **«Не посмотрели»** → тайтл
  возвращается в пул как обычно

## Добавление в коллекцию
1. **Поиск по названию**: пользователь вводит текст → список подсказок (постер, название, год, категория)
   → выбирает нужный. По умолчанию поиск в **TMDB**, переключатель — поиск в **Кинопоиске**.
2. **По ссылке**: вставить ссылку TMDB, IMDb или Кинопоиска → тайтл определяется автоматически.
   - IMDb → поиск в TMDB по IMDb ID
   - Кинопоиск → через провайдер Кинопоиска (неофициальный API, например kinopoisk.dev), из ответа
     берутся IMDb/TMDB ID, чтобы связать с тем же тайтлом
3. Перед созданием нового тайтла проверяется, нет ли его в каталоге по любому внешнему ID — дубликатов нет.
4. Если тайтл уже есть в моей коллекции → сообщить, а не добавлять второй раз.

Источники данных подключаемые: интерфейс `ITitleMetadataProvider`, реализации `Tmdb` (по умолчанию)
и `Kinopoisk`. Ключи API — в конфигурации. Сервер размещается за рубежом, TMDB доступен.

## Случайный выбор

### Перед выбором пользователь задаёт
- **Категория**: Фильмы (по умолчанию) или Сериалы
- **Режим**: «Вперемешку» или «По очереди»
- Галочка **«Выбирать из просмотренных»** (по умолчанию выключена). Выключена → тайтлы, по которым
  в этой группе есть Просмотр, исключаются.
- Необязательные фильтры: **максимальная длительность** (для фильмов, например «до 2 часов»), **жанр**
- Последние настройки запоминаются для группы

### Режим «Вперемешку»
1. Случайно выбирается **участник** группы среди тех, у кого есть хотя бы один подходящий тайтл.
2. Из его подходящих тайтлов равновероятно выбирается один.
Так у участника с большой коллекцией не больше шансов, чем у участника с маленькой.
«Ещё» повторяет оба шага, без уже показанных в сеансе тайтлов.

### Режим «По очереди»
- Ход переходит по кругу в порядке участников группы.
- Кандидат выбирается равновероятно из подходящих тайтлов того, **чей сейчас ход**. «Ещё» берёт
  следующего кандидата у того же участника.
- Ход **засчитывается и переходит дальше только по «Смотрим!»**, а не по «Ещё».
- Если тайтл есть в коллекциях нескольких участников, ход засчитывается тому, чей ход был в этот момент.
- Если у участника не осталось подходящих тайтлов: показать «У <имя> закончились фильмы — стоит
  добавить к следующему разу» и предложить **передать ход** следующему участнику.

### Общие правила
- Случайный выбор выполняется **только на сервере**, через `IRandomizer`, чтобы его можно было тестировать.
- Нет ни одного подходящего тайтла во всей группе → понятное сообщение и подсказка ослабить фильтры
  или добавить фильмы.
- **Анимация**: сервер сразу возвращает результат, клиент проигрывает анимацию 1,5–3 с
  («карточка вытягивается из мешка») и открывает карточку с тактильным откликом.
- Карточка кандидата: постер, название, год, жанры, длительность, **чей это тайтл** (для общего — все
  владельцы), теги владельцев, отметки «уже видел».

## Просмотр коллекций и сравнение
- Любой участник группы видит свою коллекцию и коллекции других участников, с тегами.
- Сортировка и фильтры: категория, жанр, год, длительность, тег, просмотрено ли в группе.
- Сравнение (выбрать двух участников или всю группу):
  - что есть у всех / у нескольких
  - что есть у меня и нет у другого (и наоборот)
  - распределение по жанрам у каждого
- История просмотров группы: что, когда.

## Этапы (каждый — отдельный `/feature`)
0. **Платформа**: Host, `IBotModule`, webhook, раздача Mini App, проверка initData, оболочка webapp
   (тема, роутинг по start_param, API-клиент), тестовые проекты.
   → `/feature Этап 0 из docs/product/movie-night.md: каркас платформы без модулей`
1. **Группы**: создать группу, пригласить по ссылке, вступить, список участников и их порядок,
   несколько групп у одного пользователя, выход из группы.
2. **Каталог и коллекция (TMDB)**: поиск по названию, добавление по ссылке TMDB/IMDb, категории,
   защита от дубликатов, теги (предустановленные и свои), отметка «Я уже видел», удаление из коллекции,
   просмотр своей и чужих коллекций.
3. **Случайный выбор**: сеанс выбора, режимы «Вперемешку» и «По очереди», фильтры, «Ещё», «Смотрим!»,
   передача хода, уведомление в бот, анимация.
4. **Просмотры**: «Посмотрели» / «Не посмотрели», история просмотров группы, галочка
   «Выбирать из просмотренных».
5. **Кинопоиск**: второй провайдер — поиск по Кинопоиску и добавление по ссылке Кинопоиска,
   связывание с тайтлами из TMDB.
6. **Сравнение коллекций**: общие и различающиеся тайтлы, жанры, фильтры и сортировка.

Для этапов 1–6: `/feature Этап N из docs/product/movie-night.md`

## Принятые допущения (архитектор может уточнить)
- Отметить «Посмотрели» и «Не посмотрели» может любой участник группы.
- Порядок в «По очереди» — по времени вступления в группу; менять его в MVP нельзя.
- Удаление тайтла из коллекции не удаляет историю просмотров группы.
- Если участник выходит из группы, его тайтлы больше не участвуют в выборе этой группы;
  история просмотров сохраняется.
- Язык интерфейса — русский; данные из TMDB запрашиваются с `language=ru-RU`.

## Вне MVP
- Синхронный выбор на разных телефонах в реальном времени (оба видят анимацию одновременно)
- Подборки по тегам, оценки после просмотра, голосование вместо случайного выбора
- Учёт серий/сезонов для сериалов (что смотрим, на какой серии остановились)
